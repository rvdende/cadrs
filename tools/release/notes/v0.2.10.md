Configurations for Part Studios, a Frame feature with cut lists, 4- and 5-axis CAM, user documentation, a Windows installer, and a faster, more accurate kernel.

## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.2.10-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11), installer | `cadrs-v0.2.10-x86_64-windows-setup.exe` |
| Windows x86_64 (Windows 10 or 11), portable | `cadrs-v0.2.10-x86_64-windows.zip` |
| macOS 11 or newer, Apple silicon and Intel | `cadrs-v0.2.10-universal-macos.dmg` |
| A browser with WebGPU or WebGL2 (Chrome, Edge, Firefox, Safari) | <https://cadrs.net/app/>, or `cadrs-v0.2.10-web.tar.gz` to serve yourself |

On Windows, the installer puts cadrs in your user folder and adds it to the Start Menu; no administrator rights are needed. The portable zip holds the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses: unpack it and run `cadrs.exe`, keeping `libraries/` beside it. The Linux archive is the same: unpack it and run `cadrs`. `SHA256SUMS.txt` has the files' checksums.

On macOS, open the `.dmg` and drag cadrs to Applications. The app isn't signed with an Apple Developer ID yet, so the first time macOS won't open it: right-click cadrs in Applications and choose **Open**, then **Open** again (on macOS 15 and later, open it once, then choose **Open Anyway** in System Settings › Privacy & Security). Updates on macOS are downloaded from the release page and dragged over the old app.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux, `%APPDATA%\cadrs\` on Windows and `~/Library/Application Support/cadrs/` on macOS.

## What's new since v0.2.9

- **Configurations** (#324, #341). A Part Studio can have configurations, edited in a node view; the configuration panel uses its table, and a dimension's bad configuration value is shown at its cell.
- **Frames and cut lists** (#290). A Frame feature builds beams and weldments along sketch lines, with a cut list of the members.
- **CAM** (#287). 4- and 5-axis machining, on a machine built as an assembly.
- **Documentation** (#321, #328). User documentation at <https://cadrs.net/docs>, opened from the app menu (F1); each dialog's **?** opens its section.
- **Windows installer** (#334). An installer with a Start Menu entry, beside the portable zip.
- **Kernel** (#315, #354, #358). cadrs's modelling kernel passes all 3,650 cases of [brep-conformance](https://github.com/springcraft-ai/brep-conformance)'s current suite, its NIST STEP files included, with a median case under 3 ms, and builds brep-bench's new cases. Booleans and fillets on small loops are faster (threads only where a loop is worth them, closed forms for convex polytopes and flat lofts). Chamfers at nearly flat corners and on the rims of spheres and cones, revolves with a profile point at the axis, and STEP files from Parasolid (Onshape) read as Parasolid reads them; the kernel can take Parasolid's tolerance and rules for comparing results with it. Variable-distance chamfers, and a Helix found from sampled points.
- **Mates** (#348, #350). A pick moves parts the least and keeps their other mates; when not all mates can hold, the fewest break and are shown red.
- **Assemblies** (#331, #332, #333). Placements of a part are drawn from one mesh, large assemblies rotate faster, and parts and instances can be found in the lists, with Select all instances.
- **Sketching and modelling** (#301, #303, #308, #309, #325, #329, #338). Dimension formulas are kept as typed; duplicate sketch curves are one edge and hovered regions are tinted; the origin's X, Y and Z axes can be picked as an axis, and Revolve says why it fails; Sweep can lock profile faces; a part pattern's Remove uses up the patterned part; coincident faces prefer the selected part, and hidden parts' ghosts are not picked.
- **View and input** (#313, #320, #322, #327, #345). A rotate drag turns about the part under the pointer; the view can turn normal to the sketch plane when a sketch starts; SpaceMouse zoom direction and speed, and the mouse wheel's zoom direction, can be set; the app sleeps while idle instead of drawing every frame.
- **Preferences** (#310, #268). Preferences in sections, grid and origin styles, 100 mm planes, and an improved interface.
- **Drawings** (#304). Section views open in their Part Studio, and the MCP server lays out drawing views.
- **Browser** (#336). Rebuilds run in slices of each frame, and the Rebuilding… pill counts an assembly's Part Studios together.
- **Crash reports** (#323). A log file, the panic, and a report offered at the next start.
- **Community** (#335). A Discord link in the app menu, the README and the docs.
- Bevy updated to its main branch (0.21-dev), fixing a layout panic (#349); scenario tests run without a GPU (#351, #357); faster local builds (#302, #310).

cadrs is an independent project.
