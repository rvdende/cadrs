Exact swept solids, tabs and features copied between documents, GLB import and export, patterns of thousands, and the site as the app itself.

## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.2.7-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11) | `cadrs-v0.2.7-x86_64-windows.zip` |
| macOS 11 or newer, Apple silicon and Intel | `cadrs-v0.2.7-universal-macos.dmg` |
| A browser with WebGPU, such as Chrome or Edge | <https://cadrs.net/app/>, or `cadrs-v0.2.7-web.tar.gz` to serve yourself |

The Linux and Windows archives hold the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses. Nothing needs installing: unpack it and run `cadrs` (Linux) or `cadrs.exe` (Windows), keeping `libraries/` beside it. `SHA256SUMS.txt` has the files' checksums.

On macOS, open the `.dmg` and drag cadrs to Applications. The app isn't signed with an Apple Developer ID yet, so the first time macOS won't open it: right-click cadrs in Applications and choose **Open**, then **Open** again (on macOS 15 and later, open it once, then choose **Open Anyway** in System Settings › Privacy & Security). Updates on macOS are downloaded from the release page and dragged over the old app.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux, `%APPDATA%\cadrs\` on Windows and `~/Library/Application Support/cadrs/` on macOS.

## What's new since v0.2.6

- **Exact swept solids** (#222, #223, #225). A solid carried by a slide, a turn or a screw, a polyhedron or a torus carried by any rigid motion, an end mill carried along a path and a pipe slid sideways are now built as exact faces, where before they were meshes or failed. Cuts by a swept solid (threads, slots, keyways) are exact too. On [brep-bench](https://brepbench.org) cadrs builds every case, none of them meshed.
- **Faster sweeps and booleans** (#220, #221, #225). The benchmark's cases run in about half the time they took before, with the measures unchanged.
- **Shells of cones** (#225). A cone or frustum whose wall closes before it reaches the opening is now hollowed correctly, sealed where the wall closes.
- **A rounded rim on a B-spline cylinder is a torus** (#225). A cylinder read as a B-spline surface (as some STEP files have it) gets the same exact round as a plain cylinder.
- **GLB import and export** (#219). Models come in and go out as glTF binary.
- **Tabs and features between documents** (#226). Copy on a tab, then Ctrl+V or Paste (the tab bar's menu, or +) in another document, also one open in another running cadrs: the tab arrives with its features and the tabs it uses. A tab also exports as a `.cadrs` file that Import reads back. Features and feature folders copy the same way, with Copy in their menus or Ctrl+C, and paste into another Part Studio at the rollback bar.
- **Pictures on parts** (#226). An Image feature shown from both sides no longer fails the rebuild, and every rebuild after it.
- **Open with cadrs**. cadrs is offered for STEP, IGES, BREP, STL, GLB and `.cadrs` files, and started with a model it imports it.
- **Patterns of thousands** (#209). A part pattern of 2,500 filleted parts rebuilds in a twentieth of a second (it took 10.8 s) and stays interactive while its count is dragged.
- **Ellipses stay exact** (#211). The elliptical edge of a cylinder cut at a slant is used, imprinted, trimmed and made tangent to as an ellipse, not as points along it.
- **Sketches** (#212, #213). A sketch imprints only the face it is on. A constrained point that can't reach the cursor follows as near as its constraints allow. Boolean Intersect takes targets and can keep the remainder.
- **Smaller things** (#207, #215, #219). The colour mixer drags smoothly, tiny parts no longer shake when the view turns, and the top bar links to GitHub with its star count.
- **The site** (#203, #210). <https://cadrs.net/> is the app itself, built from the latest code.
- **For kernel users** (#224). Short constructors for the kernel's inputs (`Plane::xy`, `Loop::circle`, `Profile::of`, ...) and picking faces and edges by a point.

cadrs is an independent project.
