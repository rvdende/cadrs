SpaceMouse navigation on Windows and Linux.

## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.2.4-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11) | `cadrs-v0.2.4-x86_64-windows.zip` |
| macOS 11 or newer, Apple silicon and Intel | `cadrs-v0.2.4-universal-macos.dmg` |
| A browser with WebGPU, such as Chrome or Edge | <https://cadrs.net/app/>, or `cadrs-v0.2.4-web.tar.gz` to serve yourself |

The Linux and Windows archives hold the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses. Nothing needs installing: unpack it and run `cadrs` (Linux) or `cadrs.exe` (Windows), keeping `libraries/` beside it. `SHA256SUMS.txt` has the files' checksums.

On macOS, open the `.dmg` and drag cadrs to Applications. The app isn't signed with an Apple Developer ID yet, so the first time macOS won't open it: right-click cadrs in Applications and choose **Open**, then **Open** again (on macOS 15 and later, open it once, then choose **Open Anyway** in System Settings › Privacy & Security). Updates on macOS are downloaded from the release page and dragged over the old app.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux, `%APPDATA%\cadrs\` on Windows and `~/Library/Application Support/cadrs/` on macOS.

## What's new since v0.2.3

- **SpaceMouse navigation** (#171, #174, thanks to ramime). A 3Dconnexion SpaceMouse pans, zooms and rotates the Part Studio and Assembly view, all six axes at once, about the view's pivot when there is one:
  - On Windows, cadrs reads the device itself: every 6-DoF 3Dconnexion device, the newer ones that send all six axes in one report among them.
  - On Linux, it goes through the spacenavd daemon, which needs installing (`sudo apt install spacenavd` on Ubuntu and Debian).
  - A push moves the view the same way, at the same speed, on both. A cap that doesn't settle exactly on zero doesn't creep the view.
  - It steers the view wherever the pointer is, while the cadrs window has focus.
  - There's no SpaceMouse support on macOS or in the browser yet.

cadrs is an independent project.
