Public documents in the browser, names that follow a rename, and `--quick-start`.

## Downloads

| Platform | File |
|---|---|
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `cadrs-v0.2.6-x86_64-linux.tar.gz` |
| Windows x86_64 (Windows 10 or 11) | `cadrs-v0.2.6-x86_64-windows.zip` |
| macOS 11 or newer, Apple silicon and Intel | `cadrs-v0.2.6-universal-macos.dmg` |
| A browser with WebGPU, such as Chrome or Edge | <https://cadrs.net/app/>, or `cadrs-v0.2.6-web.tar.gz` to serve yourself |

The Linux and Windows archives hold the executable, its `libraries/` folder (the built-in symbols, footprints and 3D models), the README and the licenses. Nothing needs installing: unpack it and run `cadrs` (Linux) or `cadrs.exe` (Windows), keeping `libraries/` beside it. `SHA256SUMS.txt` has the files' checksums.

On macOS, open the `.dmg` and drag cadrs to Applications. The app isn't signed with an Apple Developer ID yet, so the first time macOS won't open it: right-click cadrs in Applications and choose **Open**, then **Open** again (on macOS 15 and later, open it once, then choose **Open Anyway** in System Settings › Privacy & Security). Updates on macOS are downloaded from the release page and dragged over the old app.

On Linux, the app needs a Vulkan-capable GPU driver, and ALSA and udev (present on desktop distributions). The Windows build isn't code-signed, so SmartScreen may warn the first time: choose **More info › Run anyway**.

Documents are saved in `~/.local/share/cadrs/` on Linux, `%APPDATA%\cadrs\` on Windows and `~/Library/Application Support/cadrs/` on macOS.

## What's new since v0.2.5

- **Public documents in the browser** (#202). The web app at <https://cadrs.net/app/> now goes online like the desktop app: it finds other cadrs users through `peers.cadrs.net`, lists everyone's public documents, and can view, star, fork and publish them. In a browser, **Connect when cadrs starts** is on by default; the desktop app still stays offline until you connect. Each account in the browser keeps its cadrs ID across visits.
- **Your name follows a rename** (#202). Change your name in the account menu, and other people see the new name on all your public documents, without publishing them again.
- **`cadrs --quick-start`** (#199). cadrs opens your most recently modified document, or a new Untitled document if there are none, instead of the documents page, so you can start drawing at once. In the browser it's `?quick-start` in the address.
- **The site** (#199). The front page of <https://cadrs.net/> now runs cadrs itself, full width, instead of a screenshot. Click it to use it; until then the page scrolls as usual. On a phone it loads only when you ask.

cadrs is an independent project.
