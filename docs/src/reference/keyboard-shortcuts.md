# Keyboard shortcuts

In cadrs, **Shift+/** (or the app menu's **Keyboard shortcuts**) opens this list, with a search box. Letter keys act on the tab that is open: the same key can do one thing in a Part Studio and another in a sketch.

## General

| Keys | Action |
| --- | --- |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> | Accept & repeat command |
| <kbd>Enter</kbd> | Accept command |
| <kbd>Escape</kbd> | Cancel |
| <kbd>Space</kbd> | Clear selection |
| <kbd>Ctrl</kbd>+<kbd>=</kbd> or <kbd>Ctrl</kbd>+<kbd>-</kbd> | UI scale up or down |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete selection |
| <kbd>Shift</kbd>+<kbd>/</kbd> | Keyboard shortcuts |
| <kbd>F1</kbd> | Documentation |
| <kbd>\[</kbd> | Measure |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Alt</kbd>+<kbd>C</kbd> | Search tools |
| <kbd>Alt</kbd>+<kbd>click</kbd> | Look here: point it out to everyone in a shared document |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
